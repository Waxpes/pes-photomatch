Réglages

Par défaut les votes et les photos restent dans ce navigateur. Pour voter depuis plusieurs appareils, connecte une base Firebase, partage les photos, puis diffuse le lien ou le QR code.

Mode local uniquement

Étape 1 : projet Firebase gratuit

Va sur console.firebase.google.com, crée un projet et active Realtime Database. Dans les règles, colle :

{ "rules": { "pes": { ".read": true, ".write": true } } }

Étape 2 : colle l'URL de ta base

Format US : …firebaseio.com · Format EU : …europe-west1.firebasedatabase.app

Étape 3 : partage les photos

Envoie une copie allégée des photos chargées sur ce poste (1080 px) dans Firebase, pour que les autres appareils les voient sans rien sélectionner. Les originaux restent sur ton poste. Si l'envoi est interrompu, relance-le : les photos déjà envoyées sont ignorées.

Étape 4 : partage le lien ou le QR code

Ce lien connecte automatiquement l'appareil à Firebase et charge les photos partagées.

Scanne pour voter depuis n'importe quel appareil

Sauvegarde des votes

Les votes vivent dans Firebase. Garde une copie sur ce poste en cas de problème : le fichier contient tous les votes et le classement, et peut être restauré.

Zone sensible

Remettre les votes à zéro supprime uniquement les votes (Firebase compris). Les photos partagées restent en place. Télécharge une sauvegarde avant.

Supprimer les photos partagées libère la place dans Firebase (pour les renvoyer dans un autre format par exemple). Les votes sont conservés.
