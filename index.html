🔥 Configuration multi-device

Par défaut les votes restent dans ce navigateur. Pour voter depuis plusieurs appareils en simultané, connecte une base Firebase gratuite et partage le lien QR ci-dessous.

⬤  Mode local uniquement

Étape 1 — Projet Firebase gratuit

Va sur console.firebase.google.com → Nouveau projet → Active le Realtime Database (mode test). Dans les règles, colle :

{ "rules": { ".read": true, ".write": true } }

Étape 2 — Colle l'URL de ta base

Realtime Database → copie l'URL. Format US : …firebaseio.com · Format EU : …europe-west1.firebasedatabase.app

Étape 3 — Partage le lien ou QR code

Une fois connecté, ce lien auto-connecte tous les appareils à Firebase. Partage-le ou affiche le QR code au séminaire.

Scan → vote depuis n'importe quel appareil
